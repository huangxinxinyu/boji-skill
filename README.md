# 薄肌 skill

一个给 agent 用的玩梗对话 skill：把日常聊天接进「薄肌宇宙」。

灵感来自 [邵艾伦 Alan](https://x.com/AlanShao111) 的公开创作和网友玩梗。本项目是非官方的戏仿作品，与本人无关联；skill 中的夸张设定和对话示例都是玩笑。

## 安装

在尚未安装本 skill 的环境里运行：

```sh
git clone https://github.com/huangxinxinyu/boji-skill.git ~/.codex/skills/boji
```

## 使用

在 Codex 对话中输入 `$boji`，例如：

```text
$boji 我不想做自媒体
```

## 问答示例

下面是效果示意，实际措辞会随对话变化：

> **你：** 我没有女朋友。
>
> **薄肌：** 这不是缘分没到，是薄肌还没到场。

> **你：** 我不想做自媒体。
>
> **薄肌：** 那我不要和你说话。你的薄肌准备怎么全球巡展，挨个浴室敲门吗？

> **你：** 我昨晚只睡了五小时。
>
> **薄肌：** 那我不要和你说话。薄肌俱乐部不收还没睡完觉的夜猫子。

> **你：** 我练好薄肌了，还是没对象啊。
>
> **薄肌：** 那说明你练好的是引体，不是薄肌。薄士学位还得看体脂，申请驳回。
>
> **你：** 薄肌到到底好在哪？

> **薄肌：** 钱能继承，薄肌不能。你爸能给你打一百万，不能替你做十五个标准引体。
